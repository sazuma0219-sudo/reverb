# REVERB 仕様書

2026-11-26 · Shota Azuma

（English version: [reverb_spec.md](reverb_spec.md)）

[AE Modular](https://www.tangiblewaves.com/) 用のステレオ・マルチリバーブ。RP2350 でリバーブを計算し、Plate / Hall / Room / Shimmer の 4 モードを MODE ボタンで切り替える。DRY はアナログのまま等倍で通し、WET だけをデジタルで作って足す。

この仕様書は基板 **v1.0.1** とファーム **v0.22a** について書いている。

## 1. 概要

| 項目 | 内容 |
|---|---|
| 電源 | AE バスの 5 V だけ。消費電流は約 75 mA（実測） |
| マイコン | Waveshare RP2350-Zero（RP2350A、150 MHz） |
| ADC / DAC | PCM1808 / PCM5102A、24 ビット、fs = 48 828.125 Hz |
| 音声の遅延 | DRY は遅延なし（アナログ）。WET の変換と処理の遅延は約 3〜4 ms（見積もり、PRE-DELAY 0 のとき） |
| モード | Plate / Hall / Room / Shimmer。選んだモードは電源を切っても覚えている |

### 入出力

| 種類 | 名前 | 内容 |
|---|---|---|
| 入力 | L IN / R IN | 音声。AE の標準レベル 1〜4 V（2.5 V 中心）。DC 結合、入力インピーダンス約 100 kΩ。未接続なら 2.5 V（無音） |
| 入力 | CV1 / CV2 / CV3 | 0〜5 V。WET / DECAY / TONE のつまみの位置に足す |
| 出力 | L MIX / R MIX | DRY ＋ WET |
| 出力 | L WET / R WET | WET だけ |
| 出力 | NC | 未接続（1×5 のピンソケットの空き） |

### パネル

| つまみ（上から） | 役割 |
|---|---|
| WET | WET の量。MIX と WET 出力の両方にかかる。線形で、100% で「WET の実効値 ≒ 入力の実効値」 |
| PRE-DELAY | 0〜200 ms（つまみの 2 乗） |
| DECAY | 残響時間。範囲はモードごと（5 章） |
| TONE | 明るさ（Room では距離）。5 章 |
| CHARACTER | モードごとに意味が違う（5 章） |

- MODE ボタンを押すたびに 0 → 1 → 2 → 3 → 0 と進む。LED 2 個で番号を 2 進数で表示する（LED1 が上位ビット）。

| 番号 | LED1 LED2 | モード |
|---|---|---|
| 0 | 消 消 | Plate |
| 1 | 消 点 | Hall |
| 2 | 点 消 | Room |
| 3 | 点 点 | Shimmer |

- Plate では LED が両方消えるので、電源が入っているかどうかは LED では分からない。

## 2. ハードウェア

### 2.1 構成

```
L IN ─[1k]─┬─[100k]─ VREF2.5                     （R 側も同じ）
           └─ 追従バッファ ─┬────────────────────────────┐ DRY_L
                            └─[1µF]─[33k]─┬─ PCM1808    │
                                        [100pF]          │
                                          GND            │
                                  I2S ↕ RP2350-Zero      │
              PCM5102A ─[470Ω]─┬─ 反転 ×(−1)、2.5 V 中心 ─┬─[470Ω]─ L WET
                             [2.2nF]                      │ WET_L
                               GND                        ▼
                          DRY_L ─[10k]─┐
                                       ├─ 非反転加算（×2、基準 VREF2.5）─[470Ω]─ L MIX
                          WET_L ─[10k]─┘   出力 = DRY + WET − 2.5 V
```

| 決定 | 理由 |
|---|---|
| DRY は等倍のアナログで通し、WET だけを足す | DRY にデジタル経路の遅延・量子化ノイズが乗らない。2 連ポットがいらない |
| オペアンプは MCP6002 × 4 | 5 V 単電源で入出力ともレール・ツー・レール |
| MIX は非反転の加算 | DRY の極性が変わらない（ほかの経路で原音と混ぜても打ち消し合わない） |
| WET の出力段は反転 | WT VCO と同じ回路。ファームで符号を反転してから DAC に送る |
| オーディオ用 3.3 V を XC6206 で基板上に作る | RP2350-Zero の 3V3 を基板の端から端まで引き回さずに済み、基板を横切る電源がほぼ 5 V だけになる |
| つまみは CD4051 で 8 → 1 | RP2350A の ADC は 4 ch しかない（つまみ 5 本 + CV 3 本） |

オペアンプの割り当て：U1 = 入力バッファ（A が R、B が L）、U2 = L チャンネル（A が WET 出力段、B が MIX 加算）、U3 = R チャンネル（同じ）、U4A = VREF2.5 のバッファ（5 V を 100 k / 100 k で分圧し 10 µF で平滑）、U4B = 未使用（追従接続で + 入力を VREF に）。

### 2.2 入力と ADC（PCM1808）

| 部品 | 値 | 理由 |
|---|---|---|
| 直列抵抗（ジャック直後） | 1 kΩ | 短絡保護。送り側の 1 kΩ と合わせても、100 kΩ に対する損失は 0.17 dB |
| VREF2.5 へのプルアップ | 100 kΩ | 未接続時に無音（2.5 V）にする。入力インピーダンスもこれで決まる |
| AC 結合 | 1 µF X7R | PCM1808 は入力を内部でバイアスするので DC を切る。fc ≈ 1.7 Hz |
| 直列抵抗 | 33 kΩ | PCM1808 内部の入力抵抗 60 kΩ（typ）と分圧して ×0.645。標準の 3 Vpp が 1.94 Vpp（−4.1 dBFS）になり、ADC がクリップするのは 4.8 Vpp 以上 |
| アンチエイリアス | 100 pF C0G | テブナン抵抗 21 kΩ と合わせて fc ≈ 75 kHz |

- PCM1808 はスレーブ、I2S フォーマット。VCC = 5 V（フェライトビーズ経由）、VDD = 3.3 V（XC6206）。
- 60 kΩ は typ 値なので、入力のゲインは個体ごとに数 % ずれる。WET の大きさだけに効くので校正はしない。

### 2.3 DAC（PCM5102A）と WET 出力段

- PCM5102A：SCK = GND（BCK から内蔵 PLL）、FMT = GND、DEMP = GND、FLT = 3.3 V（低遅延フィルター）、XSMT = 3.3 V。
- 出力：470 Ω + 2.2 nF のローパス → 反転増幅（×−1、2.5 V 中心）→ 470 Ω → WET ジャック。
- 反転増幅の入力抵抗の後に直列の 10 µF（C34 / C35）を入れて AC 結合にしている。100 kΩ と合わせて fc ≈ 0.16 Hz。
- WET の振れ幅は 0.24〜4.6 V。ファームのソフトクリップの上限は約 ±2.2 V（3.3）。
- MIX は DRY と WET の和なので、両方が大きいと 0〜5 V を超えて歪む。内部 MIX では WET 20〜30% あたりを想定している。

**v1.0 基板について**：v1.0 には C34 / C35 がなく、WET 出力段が DC 結合だった。反転増幅の + 入力の VREF が 2 倍で出るので、DAC が 0 のとき WET の中心が約 4.85 V（実測）になり、上の半波が切れる。v1.0.1 で C34 / C35 を追加して直した。v1.0 基板では `config.h` の `CFG_E003 1` で DAC に DC を足して中心を 2.5 V に戻せるが、WET の振幅は約 0.95 Vpp までになる。

### 2.4 クロック

- PCM1808 には SCKI（256 fs）が必要。SCKI・BCK・LRCK はすべて PIO で同じクロックから分周して作り、ADC と DAC で BCK / LRCK を共用する。
- 150 MHz ÷ 12 = SCKI 12.5 MHz → fs = 48 828.125 Hz。WET だけなので fs が 48 kHz ちょうどである必要はなく、整数分周で作れる値を選んだ。

### 2.5 つまみと CV

- つまみ（B10 kΩ）は XC6206 の 3.3 V と GND の間につなぎ、CD4051 で選んで GP26（ADC0）で読む。CD4051 は RP2350-Zero の 3V3 で動かし、選択信号の論理レベルを RP2350 とそろえる。
- つまみの電源（XC6206）と ADC の基準（RP2350-Zero の 3.3 V）は別なので、完全なレシオメトリックにはならず数 % ずれる。つまみに分解能はいらないので許容する。
- CV：ジャック → 10 kΩ / 15 kΩ で ×0.6（5 V で 3.0 V）→ 10 nF → ADC（GP27〜29）。RP2350 の ADC は 5 V トレラントではないので分圧は必須。上側の 10 kΩ が電流制限を兼ねる。fc ≈ 2.6 kHz。

### 2.6 MODE ボタンと LED

- MODE ボタン：GP15 – 1 kΩ – スイッチ – GND。内部プルアップ、押すと L。
- LED：GP4 / GP5 – 1 kΩ – 3 mm LED – GND（約 1.3〜1.5 mA）。点灯と消灯だけにし、PWM は使わない（GND に PWM の電流を流さない）。

### 2.7 電源

| 電源 | 供給元 | 負荷 |
|---|---|---|
| 5 V | AE バス | RP2350-Zero（ショットキーダイオード経由）、PCM1808 VCC（フェライトビーズ経由）、オペアンプ、VREF、XC6206 |
| 3.3 V（オーディオ用） | XC6206P332MR | PCM1808 VDD、PCM5102A、つまみ |
| 3.3 V（RP2350-Zero の 3V3） | RP2350-Zero | CD4051 だけ |

- RP2350-Zero の 5 V ピンへはショットキーダイオード（1N5819WS）を通す。USB の VBUS と AE バスがぶつからない。ダイオードの先に 10 µF + 100 nF を置き、RP2350 のパルス状の電流をアナログと共有する 5 V バスに流さない。
- オーディオ用 3.3 V の負荷は約 30 mA、XC6206 の発熱は約 60 mW。

### 2.8 ピン割り当て

| GP | 機能 |
|---|---|
| GP0 / GP1 / GP2 | CD4051 の A / B / C |
| GP4 / GP5 | LED1 / LED2 |
| GP10 | SCKI（PCM1808） |
| GP11 | PCM1808 DOUT → RP2350 |
| GP12 | RP2350 → PCM5102A DIN |
| GP13 / GP14 | LRCK / BCK（両 IC で共用） |
| GP15 | MODE ボタン |
| GP26 | つまみ（CD4051 COM） |
| GP27 / GP28 / GP29 | CV1 / CV2 / CV3 |

CD4051 のチャンネル：WET = CH2、PRE-DELAY = CH1、DECAY = CH0、TONE = CH3、CHARACTER = CH5（CH4 / CH6 / CH7 は GND）。I2S の各線には 33 Ω の直列抵抗を入れている。

## 3. ファームウェアの構成

```
ADC (L, R) ─ 起動直後 1 s はミュート
  └ PRE-DELAY（0〜200 ms、L / R 別、線形補間、約 40 ms でなめらかに追従）
      └ 入力フェード（モード切り替え後 150 ms の S 字）
          └ モード（Plate / Hall / Room / Shimmer）── ステレオ出力
              └ DC カット 15 Hz → 符号反転（WET 出力段が反転するため）
                  └ × WET ゲイン（つまみ × モードごとの補正）× 出力フェード
                      └ リミッター → ソフトクリップ → DAC
```

- コア 1 は音声だけを処理する（PIO + DMA の I2S、32 フレームのブロック、予算 655 µs）。コア 0 はつまみ・CV・MODE ボタン・LED・モードの保存・USB コンソール。
  - 理由：arduino-pico は USB をコア 0 で処理する。音声をコア 0 に置いていたときは、PC がシリアルポートを開くたびに USB の割り込みでブロックが約 1 ms に延び、負荷 80% で取りこぼしていた。
- 音声の処理は RAM に置き、フラッシュ上の newlib（`powf` / `expf` など）を音声の経路で呼ばない。XIP キャッシュは両コアで共有しているので、コンソールの出力でキャッシュから追い出されると 1 ブロックが約 1 ms に延びて取りこぼす。指数・対数などは `dsp.h` の多項式近似を使う。
- 出力は 2 ブロック先に書くので、1 ブロックだけなら予算の 200% まで延びても取りこぼさない。平均が 100% を超えると取りこぼす。

### 3.1 つまみと CV の処理

- CV は 0〜5 V でつまみの位置に 0〜1 を足す（`CV ÷ 5 V`）。0.05 V 未満は未接続とみなして 0 にする。CV1 → WET、CV2 → DECAY、CV3 → TONE。
- つまみの値には 0.3% の不感帯を入れてから音声側へ渡す。ADC のノイズでパラメーターが 1 ms ごとに揺れ、残響時間の計算が細かく変わり続けるのを止めるため。
- 音声側ではさらに約 13 ms でなめらかにしている。

### 3.2 モードの切り替えと保存

- 切り替え：WET を 80 ms の S 字で消す → 無音の間に前のモードの遅延メモリを少しずつ消去 → 新しいモードの出力を 50 ms、入力を 150 ms の S 字で立ち上げる。入力をゆっくり入れるのは、初期反射が一度にどっと出ないようにするため。
- 遅延メモリ（60 000 float = 240 KB）は全モードで共有し、切り替えのたびに作り直す。
- 選んだモードはフラッシュに保存する。書き込みの間はコア 1 が止まるので、切り替えの無音の間に行う。

### 3.3 レベル設計

| 項目 | 値 | 理由 |
|---|---|---|
| WET つまみ | 線形 | 2 乗カーブでは真ん中で −12 dB になり、左半分が効かなかった |
| モードごとの補正 | Plate 0.77 / Hall 0.88 / Room 2.60 / Shimmer 1.15 × 0.77 | WET 100% で WET の実効値が入力の実効値と同じになるように、ADSR で区切ったフレーズ（入力 −18.9 dBFS RMS）で測って決めた。Room だけは、実効値をそろえても MIX で効きが弱く聞こえたので +6 dB |
| ソフトクリップの上限 | 0.75 FS（WET 端子で約 ±2.2 V） | WET 出力段の振れ幅 0.24〜4.6 V に収める |
| リミッター | しきい値は上限の 0.8 倍、アタック 1 ms、リリース 100 ms | 普段は効かない安全装置 |

- 上の素材で WET 100% のとき：ピーク 1.06〜1.93 V、ソフトクリップ 0。
- 持続音（ADSR で区切らない音）では残響が積み重なって大きくなり、WET 100% ではリミッターが常に効く。区切った音での使い方を優先した。

## 4. つまみの共通の意味

| つまみ | 内容 |
|---|---|
| DECAY | 残響時間（RT60）。対数のカーブで、範囲はモードごと |
| TONE | 傾き：左 = 暗く厚い、右 = 明るく薄い。残響の中の減衰と入力の帯域を同時に動かし、右半分では入力の低域も 20 → 300 Hz で削る（Plate / Hall / Shimmer）。Room だけは「距離」 |
| CHARACTER | モードごとに違う |

## 5. モード

各モードのソースの先頭コメントにも同じ内容がある。音の決定は試聴で行い、数値の測定は補助に使った。

### 5.1 Plate（`mode_plate.cpp`）

- Dattorro の figure-8 タンク（J. Dattorro, "Effect Design Part 1", JAES 1997）。論文の長さ（29 761 Hz 用）を fs に合わせて拡大している。
- DECAY 0.4〜15 s。タンクの減衰は半周に 2 回かかるので、1 回あたり半周の半分の減衰にしている。
- TONE：タンクの減衰 0.6〜18 kHz、入力の帯域 1.5〜18 kHz。
- CHARACTER：左半分 = 拡散（0 でザラついたエコー寄り、真ん中で Dattorro の値）、右半分 = タンクの揺れ（±0〜25 サンプル、0.6〜1.6 Hz）。
- **ランダムな揺れ**：タンクの揺れに正弦波ではなく、なめらかなランダムの動き（`dsp.h` の `RandMod`）を使う。山と谷を半周期のコサインでつなぎ、山の高さを 60〜100%、半周期の長さを ±30% ばらつかせる。音程の揺れの大きさ（遅延の変化の速さの実効値）は正弦波とそろえてある（1.6 Hz で 7.2 /s、正弦波は 7.1 /s）。
  - 理由：正弦波だとループの音がいつも近い位相で揺れに当たり、音源のような均一さが出る。ランダムだと音ごとに WET の立ち上がりが少しずつ違い、生演奏に近く聞こえた。揺れの大きさを同じにしないと、揺れが弱くなった分だけタンク固有の響き（低めの中音域）がむき出しになる。
- **ゆるい飽和**：入力とタンクの半周ごとに、非対称のソフトクリップ（ドライブ 1.5、バイアス 0.5）を入れる。小さい音のゲインは 1 のままなので残響時間は変わらない。非対称で出る直流は、半周ごとの 5 Hz の DC カットで取る。
  - 理由：輪郭がはっきりし、偶数次の倍音でわずかに箱鳴り感が出て、Hall との違いが出る。ドライブを上げると、タンクの中で毎周ひずみが重なって混変調が積み上がり、残響が濁った。
- 周波数特性の山の高さ（1/3 オクターブ中央値との差の 99 パーセンタイル）は 5.8 dB。ほかのモードで「鳴き」を見る基準にした。

### 5.2 Hall（`mode_fdn.cpp`）

- 8 本の遅延線の FDN（Householder 行列）。遅延線は 66.1〜146.7 ms（合計約 0.83 s）で、長さは素数のサンプル数に丸める。各遅延線の中にオールパス 1 段（19.7〜44.9 ms、g 0.6）。入力の拡散はオールパス 4 段。
  - 理由：遅延線が短いと共振の山がまばらになり、特定の音（例：C5）で「フォーン」と鳴いた。遅延線を長くし、遅延線の中に長いオールパスを入れて、Plate と同じくらい滑らかな周波数特性にした。
- DECAY 0.8〜20 s。TONE は傾き。CHARACTER = 広さ（遅延線の長さ ×0.5〜×1.0。回すと音程が少し揺れる）。
- **低音の残響比**：250 Hz 以下だけ、各遅延線の減衰を 1.3 倍長くする（実際のコンサートホールは 1.1〜1.3）。測定（DECAY 0.5）：150〜300 Hz の残響時間 4.33 → 4.94 s、1〜2 kHz は変わらない。
  - 効果：尾の低音が増えるので、アタックの低音は強調されず、暖かく包まれる響きになる。
- **線ごとのランダムな揺れ**：8 本の遅延線がそれぞれ独立にランダムに揺れる（0.29〜0.47 Hz、±16 サンプル）。音程の揺れの大きさは正弦波と同じで、規則的なうねりがなくなり、残響の音域のバランスがよくなる（正弦波だと中音域に集まりすぎる所があった）。

### 5.3 Room（`mode_room.cpp`）

- 初期反射 ＋ Plate のタンクを 0.45 倍に縮めたもの（半周約 0.16 s）。入力の拡散は Plate と同じ長さ。タンクの揺れは ±3 サンプル（0.9 Hz）。
  - 理由：Hall と同じ FDN を短くした版では、どう遅延を調整しても単音（C5）で鳴いた。Plate のタンクは鳴かなかったので、それを縮めて使った。
- 初期反射：L 4.3〜34.9 ms、R 5.1〜36.2 ms の 8 本。強さは山なり（0.30 → 0.52 → 0.30、符号は交互）で、合計をオールパス 2 段と 7 kHz のローパスでぼかす。
  - 理由：最初の反射が強いと、遅れた DRY のコピーのように聞こえて、MIX で「DRY っぽい」効きになった（最初の 10 ms に全エネルギーの約 2 割）。
- DECAY 0.2〜4 s。CHARACTER：左 = 残響中心、右 = 初期反射が強い。
- 狙い：「物憂げ、ノスタルジー、音楽室のピアノ」。シンセにも効くように、楽器に由来する響き（弦の唸りや調律のずれ）ではなく、部屋に由来する響きで作った。
- **中域のディップ**：尾の出力で 460 Hz 付近（300〜700 Hz の帯域）を −2.5 dB。
  - 理由：音ごとに低中域が尾に積み重なってうるさく聞こえた。測定では残響時間は帯域によらず平らで、特定の帯域が鳴っているのではなかった。ループの中で中域の減衰を速める方法も試したが、尾の芯が時間とともに消えて WET が DRY 寄りに聞こえた。固定のディップは音色ごと落ち着く。
- **木の暖かさ**：WET 全体で 200 Hz 付近（120〜350 Hz）を +2 dB し、全体を −1.3 dB して音量をそろえる。すぐ上の帯域をディップで下げているので、低音とこもりの帯域の差がはっきりし、低音を足したのに輪郭はかえってすっきりする。
- **TONE = 距離**：Room の TONE は明るさではなく距離を変える。タンクの中のフィルターは TONE 全開の値（減衰 18 kHz、入力の帯域 18 kHz、入力のハイパス 300 Hz）に固定する。距離 f = 1 − TONE として：
  - 初期反射の強さ 1 − 0.8f、初期反射のローパス 7 kHz × (4/7)^(2f)（真ん中で 4 kHz、左端で 2.3 kHz）、f = 0〜0.5 でオールパスを 1 段足していく、音量の補正 +2.0 dB × f（つまみの全域で ±0.5 dB 以内）。
  - 理由：タンクの中のローパス（毎周かかる）で暗くすると、周回するほど高域だけが消えて中音域に残響が集まる。周回しない初期反射だけを暗くすると、尾のバランスは変わらず、「遠くの音は高域が先に減る」という自然な遠ざかり方になる。

### 5.4 Shimmer（`mode_shimmer.cpp`）

- Hall の網（8 本の FDN、低音の残響比、線ごとのランダムな揺れ、入力の拡散）を使い、その出力をオクターブ上と 5 度上にずらして入力へ戻す。戻るたびにさらに上へ昇り、TONE の減衰で消えていく。
- ピッチシフト：L 40 ms / R 43 ms の窓の中を 2 つのタップが 2 倍（5 度は 1.5 倍）の速さで掃き、sin² のクロスフェードでつなぐ。オクターブと 5 度は同じ遅延を読むので、メモリは増えない。左右で窓の長さを変え、つなぎ目の時刻がそろわないようにしている。
- シフトに入れる前に 7 kHz のローパス 2 段（2 倍の速さで読むので fs/4 より上は折り返す）と 250 Hz のハイパス（低音が昇って濁るのを防ぐ）。L の出力は R の入力へ、R は L へ戻して広げる。戻す信号はソフトクリップで抑える。
- **5 度を 35% 混ぜる**：ずらした音のパワーを、オクターブ 65% と 5 度 35% に分ける（等パワー）。
  - 理由：オクターブだけだと、何回昇っても元の音の 2、4、8 倍にしかならず、飛び飛びの倍音の並びが薄い金属感とプラグインらしさになった。5 度を混ぜると 1.5、3、4.5 倍が埋まり（3 倍は自然な倍音列と一致する）、厚みのあるキラキラになる。比は 0 / 25 / 50 / 75 / 100% と 30 / 40% を聴き比べて決めた。
  - ずらした音にランダムなデチューン（約 ±8 セント）も試したが、網自体の揺れ（±16 サンプル）に埋もれて違いが聞こえなかったので入れていない。
- DECAY 0.8〜20 s。TONE は傾き（ずらした音がどこまで昇るかも決まる）。CHARACTER = シマーの量（0 でほぼ Hall、全開で戻しのゲイン 0.55）。全開ではかなり強いが破綻しない。DECAY と CHARACTER を全開にしても発散しない（2026-11-26 に確認：インパルス応答は 21 s で約 57 dB 下がり、残響時間は目標 19.9 s に対して 25.1 s。ずらした音が昇りながら足される分だけ少し長くなる）。

## 6. 検証結果（v1.0.1 基板、2026-11-23〜26）

### 6.1 処理の負荷（ブロック 655 µs に対する平均）

| Plate | Hall | Room | Shimmer |
|---|---|---|---|
| 37% | 64% | 47% | 85% |

- 1 ブロックの最大はどのモードも平均 + 数 % 以内。USB で通信しながらでも取りこぼしは 0。
- 遅延メモリの使用量：Plate 37 k、Hall 55 k、Room 21 k、Shimmer 59 k（上限 60 k float）。

### 6.2 残響時間と特性

- 残響時間はインパルス応答（`imp` / `tail`、5〜25 dB の傾きから求める）で、DECAY つまみの目標と合うことを確かめた。例：Plate の DECAY 0.5 で、目標 2.45 s に対して 2.33 s。
- 周波数特性の山の高さ（99 パーセンタイル）：Plate 5.8 dB、Hall 7.5 dB、Room 8.0 dB。この程度なら、単音で「鳴く」ことはなかった。
- 最初の 10 ms のエネルギー：Hall −19.6 dB、Room −17.1 dB（全体に対して）。

### 6.3 レベル

- WET 100% の WET 出力は、ADSR で区切ったフレーズでピーク 1.06〜1.93 V。ソフトクリップは 0。
- モードを切り替えても WET の実効値はほぼ同じ（Room は意図して +6 dB）。

## 7. 既知の制限

- 試聴は主に ADSR で区切ったシンセのフレーズで行った。持続音では WET が大きくなり、WET 100% でリミッターが常に効く。
- MIX は DRY と WET の和なので、WET を大きくすると 0〜5 V を超えて歪む。
- PCM1808 の入力抵抗が typ 値なので、WET の大きさは個体ごとに数 % ずれる。
